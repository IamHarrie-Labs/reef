# Reef research walkthrough

The MP4 is a ninety-second, captioned walkthrough assembled from actual
production-browser captures. It is an edited sequence of states, not a continuous
screen recording. It has no voice track and does not claim participant feedback.

Sequence: compare QQQ/TQQQ and SMH/SOXL at $25k for thirty days, reverse funding,
change the hold to seven days, inspect requirements, export the notebook, then
inspect the separate historical proof case. Read the dated scenario in each
capture; the hourly desk can change after recording.

To rebuild after capturing new screenshots, install Pillow and imageio-ffmpeg
locally, then run `render_demo.py`. The script expects the six named captures in
this directory. The runtime used here is ignored by Git and deployment.

Running `render_demo.py` produces `reef-research-walkthrough.mp4`. Historical proof timestamps
establish content commitment, not authenticated exchange origin or actual fills.
