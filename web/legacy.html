The model

Signed positions: A = -beta times reference notional; B = reference notional. Returns are per B-leg reference amount, not collateral ROI. Direction is selected on earlier funding data and assessed on later complete days. Costs are weighted in dollars.

Limits

Historical estimates, not realised trading performance. Book snapshots cannot guarantee fills; exit costs assume the same book. Risk uses square-root-time scaling. The rank score is a heuristic, not a probability. Confidence intervals cover funding uncertainty only. SUPPORTED is conditional support, never a guarantee. UNFAVOURABLE does not prove no opportunity exists.

Self-scoring

The CLI records evidence before explanation. This static browser does not log queries. Realised scoring requires actual fills, fees, settlements and mark prices; missing data stays unscored. Legacy results are superseded.
